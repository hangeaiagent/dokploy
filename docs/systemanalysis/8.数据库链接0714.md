## 🌐 网络访问配置

### 内部网络访问 (推荐)
**通过Docker Swarm内网访问**:
```bash
# 从dokploy容器内部连接
Host: dokploy-postgres  # 服务名解析
Port: 5432
Network: dokploy-network (10.0.1.0/24)
PostgreSQL IP: 10.0.1.3
```

### 外部网络访问配置
⚠️ **当前状态**: PostgreSQL服务**未暴露外部端口**，仅允许内网访问

#### 启用外部访问的方法

**方法1: 修改Docker Service配置**
```bash
# 更新服务以暴露端口
docker service update dokploy-postgres \
  --publish-add published=5432,target=5432,protocol=tcp

# 验证端口映射
docker service ls
```

**方法2: 创建端口转发隧道**
```bash
# SSH端口转发 (推荐用于开发调试)
ssh -L 5432:10.0.1.3:5432 user@server_ip

# 然后可通过localhost:5432连接
```

**方法3: 通过dokploy容器代理**
```bash
# 在dokploy容器中创建端口转发
docker exec -it dokploy.1.xxx /bin/bash
# 在容器内部可直接访问 dokploy-postgres:5432
```

## 🔒 安全配置说明

### 当前安全配置
- **网络隔离**: ✅ 运行在Docker专用网络中
- **外部访问**: ✅ 默认禁用外部端口访问  
- **认证方式**: scram-sha-256 (安全哈希认证)
- **SSL**: 未启用 (内网通信)

### pg_hba.conf 认证规则
```conf
# 本地连接 (trust认证)
local   all             all                     trust
host    all             all             127.0.0.1/32    trust
host    all             all             ::1/128         trust

# 复制连接
local   replication     all                     trust
host    replication     all             127.0.0.1/32    trust
host    replication     all             ::1/128         trust

# 所有外部连接 (密码认证)
host    all             all             all             scram-sha-256
```

### 安全建议
1. **生产环境**: 建议定期更换数据库密码
2. **外部访问**: 仅在必要时开启，并配置防火墙规则
3. **SSL连接**: 生产环境建议启用SSL/TLS加密
4. **访问控制**: 根据需要配置更严格的IP白名单

### 性能监控查询
```sql
-- 查看活跃连接
SELECT pid, usename, application_name, client_addr, state 
FROM pg_stat_activity 
WHERE state = 'active';

-- 查看数据库统计
SELECT schemaname, tablename, n_tup_ins, n_tup_upd, n_tup_del 
FROM pg_stat_user_tables 
ORDER BY n_tup_ins DESC;
```
