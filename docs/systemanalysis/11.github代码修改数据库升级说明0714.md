## 🔒 安全注意事项

### 1. 数据加密

- `user_ai_credentials.encrypted_api_key` 字段存储加密后的API密钥
- `user_deployed_projects.api_key` 字段存储哈希值，不存储明文
- 需要在应用层实现AES-256加密/解密逻辑

### 2. 访问控制

```sql
-- 创建只读用户用于分析和监控
CREATE USER readonly_user WITH PASSWORD 'secure_password';
GRANT SELECT ON ALL TABLES IN SCHEMA public TO readonly_user;

-- 创建应用专用用户
CREATE USER app_user WITH PASSWORD 'app_password';
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE ai_marketplace_projects TO app_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE user_deployed_projects TO app_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE user_ai_credentials TO app_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE billing_records TO app_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE api_quotas TO app_user;
```

### 3. 审计日志

```sql
-- 启用行级安全策略（RLS）
ALTER TABLE user_ai_credentials ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_deployed_projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE billing_records ENABLE ROW LEVEL SECURITY;

-- 创建用户数据隔离策略
CREATE POLICY user_ai_credentials_policy ON user_ai_credentials 
FOR ALL USING (user_id = current_setting('app.current_user_id'));

CREATE POLICY user_deployed_projects_policy ON user_deployed_projects 
FOR ALL USING (user_id = current_setting('app.current_user_id'));

CREATE POLICY billing_records_policy ON billing_records 
FOR ALL USING (user_id = current_setting('app.current_user_id'));
```
