# 数据库表名称和作用

## 概述
本文档整理了 Dokploy 平台的数据库表结构，按功能模块分类说明各表的名称和作用。数据库使用 PostgreSQL 和 Drizzle ORM，支持多租户组织架构。

## 1. 核心应用管理

### **users_temp**
- **作用**: 用户账户管理，包含认证、管理员设置和指标配置
- **功能**: 2FA、邮件验证、禁用管理、SSL/证书设置、服务器指标配置、Stripe 集成

### **projects**
- **作用**: 项目组织单元，用于分组应用和服务
- **功能**: 名称、描述、环境变量、所属组织

### **applications**
- **作用**: 核心可部署应用，支持多种源类型和构建配置
- **功能**: 多源类型（GitHub、GitLab、Bitbucket、Docker等）、构建类型（Dockerfile、Nixpacks、Heroku buildpacks）、Docker Swarm 配置、预览部署、回滚支持

### **deployments**
- **作用**: 部署历史和状态跟踪，支持应用、compose 堆栈等
- **功能**: 状态跟踪、日志路径、错误处理、多种部署类型

## 2. 数据库服务

### **postgres**
- **作用**: PostgreSQL 数据库服务管理
- **功能**: 数据库凭据、Docker 镜像配置、资源限制、外部端口映射

### **mysql**
- **作用**: MySQL 数据库服务管理
- **功能**: 数据库凭据（包括 root 密码）、Docker 镜像配置、资源限制

### **mariadb**
- **作用**: MariaDB 数据库服务管理
- **功能**: 类似 MySQL 的数据库凭据和资源管理

### **mongo**
- **作用**: MongoDB 数据库服务管理
- **功能**: 数据库凭据、副本集支持、资源限制

### **redis**
- **作用**: Redis 缓存/数据库服务管理
- **功能**: 密码认证、资源限制、外部端口映射

## 3. Docker Compose & 编排

### **compose**
- **作用**: Docker Compose 堆栈管理，支持多源
- **功能**: Compose 文件处理、多 git 提供商、隔离部署、自动部署触发器

### **domains**
- **作用**: 应用和 compose 服务的域名和路由管理
- **功能**: SSL 证书管理、端口映射、路径配置、Traefik 集成

### **mounts**
- **作用**: 所有服务类型的卷和文件挂载
- **功能**: 绑定挂载、命名卷、文件挂载（包含内容）

### **ports**
- **作用**: 应用的端口映射和暴露
- **功能**: 发布/目标端口映射、TCP/UDP 协议、入口/主机模式

## 4. 基础设施和服务器管理

### **server**
- **作用**: 远程服务器管理和监控
- **功能**: SSH 连接详情、Docker 清理设置、指标配置、状态跟踪

### **certificates**
- **作用**: SSL 证书管理
- **功能**: 证书数据和私钥存储、自动续期、路径管理

### **sshKeys**
- **作用**: 服务器和 git 访问的 SSH 密钥管理
- **功能**: 私钥/公钥对、使用跟踪、组织范围

## 5. Git 提供商集成

### **gitProvider**
- **作用**: 基础 git 提供商配置
- **功能**: 提供商类型管理、组织范围

### **github**
- **作用**: GitHub App 集成设置
- **功能**: 应用凭据、安装 ID、webhook 密钥

### **gitlab**
- **作用**: GitLab 集成设置
- **功能**: OAuth 令牌、实例 URL、组管理

### **bitbucket**
- **作用**: Bitbucket 集成设置
- **功能**: OAuth 配置、工作区管理

### **gitea**
- **作用**: Gitea 自托管 git 集成
- **功能**: 实例 URL、访问令牌

## 6. 备份和恢复

### **backups**
- **作用**: 数据库备份配置和调度
- **功能**: Cron 调度、多数据库类型、保留策略、S3 兼容存储

### **volumeBackups**
- **作用**: 持久化数据的卷备份管理
- **功能**: 卷目标、cron 调度、服务关联、保留管理

### **destinations**
- **作用**: 备份存储目标（S3 兼容）
- **功能**: S3 凭据、存储桶配置、端点管理

### **rollbacks**
- **作用**: 应用回滚管理
- **功能**: 部署版本控制、完整上下文保存、镜像跟踪

## 7. 安全和访问控制

### **security**
- **作用**: 应用的 HTTP 基本认证
- **功能**: 每个应用的用户名/密码对

### **redirects**
- **作用**: 应用的 URL 重定向规则
- **功能**: 正则表达式模式、永久/临时重定向

## 8. 组织和多租户

### **organization**
- **作用**: 多租户组织管理
- **功能**: 组织元数据、所有者关系、成员管理

### **member**
- **作用**: 组织成员和权限管理
- **功能**: 基于角色的访问控制、项目/服务权限、团队分配

### **invitation**
- **作用**: 组织邀请管理
- **功能**: 邮件邀请、角色分配、过期处理

## 9. 认证和会话

### **account**
- **作用**: 用户认证账户，支持 OAuth
- **功能**: 提供商令牌、2FA 设置、密码重置、邮件确认

### **session**
- **作用**: 用户会话管理
- **功能**: 会话令牌、IP 跟踪、用户代理、模拟支持

### **twoFactor**
- **作用**: 双因素认证管理
- **功能**: TOTP 密钥、备份代码

### **apikey**
- **作用**: 程序化访问的 API 密钥管理
- **功能**: 速率限制、权限、过期、使用跟踪

## 10. 通知和监控

### **notifications**
- **作用**: 主要通知配置
- **功能**: 事件触发器（部署、错误、备份）、多通道支持

### **slack**, **telegram**, **discord**, **email**, **gotify**
- **作用**: 特定通知渠道配置
- **功能**: 平台特定设置和凭据

## 11. 高级功能

### **schedules**
- **作用**: 应用和服务的 Cron 任务调度
- **功能**: 命令执行、shell 类型选择、服务目标

### **previewDeployments**
- **作用**: 拉取请求预览部署管理
- **功能**: 分支跟踪、PR 元数据、域名分配、过期管理

### **ai**
- **作用**: AI 助手集成
- **功能**: 多 AI 提供商、API 配置、部署建议

### **registry**
- **作用**: 容器注册表管理
- **功能**: 私有注册表凭据、镜像前缀处理、自托管/云支持

### **verification**
- **作用**: 邮件/身份验证令牌
- **功能**: 验证码、过期管理

## 12. 实用工具表

### **shared.ts**
- **作用**: 包含跨多个表使用的共享枚举
- **关键枚举**: `applicationStatus`、`certificateType`、`triggerType`

## 总结

该数据库架构展示了一个全面的 PaaS 平台，具备完善的多租户架构、广泛的服务支持、强大的备份/恢复系统，以及 AI 集成和预览部署等高级功能。整个系统围绕项目、应用、服务的生命周期管理，提供了从代码部署到运维监控的完整解决方案。
