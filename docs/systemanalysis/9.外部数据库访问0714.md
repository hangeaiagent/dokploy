## 🔧 技术实现细节

### 代理容器部署命令
```bash
# 创建代理容器
docker run -d --name postgres-proxy \
  --network dokploy-network \
  -p 5432:5432 \
  alpine/socat \
  TCP-LISTEN:5432,fork,reuseaddr TCP:dokploy-postgres:5432
```

## 🔒 安全配置

### 当前安全状态
- ✅ **网络隔离**: PostgreSQL容器仅在内网可达
- ✅ **代理转发**: 通过受控代理容器进行端口转发
- ✅ **认证机制**: 使用强密码和scram-sha-256认证
- ⚠️ **SSL加密**: 当前未启用SSL (内网传输)

### 安全建议
1. **防火墙配置**: 限制5432端口仅允许必要IP访问
2. **SSL启用**: 生产环境建议启用SSL连接
3. **密码管理**: 定期更换数据库密码
4. **访问监控**: 启用连接日志和审计功能

### 防火墙配置示例
```bash
# 仅允许特定IP访问PostgreSQL端口
sudo ufw allow from [客户端IP] to any port 5432

# 或限制特定网段
sudo ufw allow from 192.168.1.0/24 to any port 5432
```

## 🔄 故障排除

### 常见问题及解决方案

#### 1. 连接被拒绝
```bash
# 检查代理容器是否运行
docker ps | grep postgres-proxy

# 重启代理容器
docker restart postgres-proxy
```

#### 2. 端口被占用
```bash
# 查看端口使用情况
netstat -tlnp | grep 5432

# 杀死占用进程
sudo kill -9 [PID]
```

#### 3. 网络连接问题
```bash
# 测试容器间网络
docker exec postgres-proxy ping dokploy-postgres

# 重新创建网络连接
docker network disconnect dokploy-network postgres-proxy
docker network connect dokploy-network postgres-proxy
```

#### 4. 认证失败
```bash
# 验证数据库用户
docker exec dokploy-postgres.1.xxx psql -U dokploy -d dokploy -c "\du"

# 重置密码 (如需要)
docker exec dokploy-postgres.1.xxx psql -U dokploy -d dokploy -c "ALTER USER dokploy PASSWORD 'new_password';"
```
